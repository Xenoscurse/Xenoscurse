### 🚀 Featured Projects

Here are the core projects I'm actively building and maintaining:

*   **[Stellar](https://github.com/Xenoscurse/Stellar)** — A full-stack anime and manga tracking platform built with React, Cloudflare Workers, and D1. Features AniList syncing, custom watchlists, and a beautiful UI.
*   **[Cronus](https://github.com/Xenoscurse/Cronus)** — A secure, silver-themed admin dashboard for Stellar. Built to manage KV caches, inspect the D1 database, monitor API health, and force AniList/Anikoto mappings.
*   **[Stellaris](https://github.com/Xenoscurse/Stellaris)** — A high-performance Rust CLI and native GUI port of `ani-cli`. Built with `egui`, focused on speed, Anikoto providers, and seamless local playback via `mpv`.
